# Visão do jogo

## O que o jogo É

- Um city builder isométrico no navegador, inspirado no Cities: Skylines.
- Uma simulação onde **cada pessoa tem uma vida própria**, do nascimento à morte, com escolhas que fazem sentido.
- Baseado na **realidade brasileira**: números, leis e costumes vêm de fontes reais (IBGE, legislação, pesquisas).
- **Leve**: cidades grandes não podem travar.
- Evoluído continuamente por agentes de IA, guiados por dados do próprio jogo.

## O que o jogo NÃO é

- Não é um jogo de ação, combate ou desastres fantasiosos.
- Não tem nada que surge do nada só para enfeitar a tela.
- Não busca gráfico fotorrealista (o estilo é low-poly bem iluminado).
- Não depende de LLM para funcionar: a IA com LLM é opcional.

## Perguntas para decidir se uma ideia entra

1. Isso existe numa cidade real? Qual a fonte?
2. Melhora a vida simulada das pessoas ou a experiência de construir a cidade?
3. Dá para medir se funcionou (métrica no relatório)?
4. Cabe no orçamento de performance?
